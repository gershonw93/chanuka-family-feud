# Latke Feud

A survey-style party game for a family Hanukkah party. One host screen (TV or laptop) plus everyone's phones, synced through the artifact's shared database.

- `latke-feud.html`: the built single-file artifact (React + Tailwind from CDN).
- `src/`: source (`app.jsx`, `logic.js`, `questions.js`, `template.html`).
- Rebuild: `npm install && node build.mjs`.
